
# DevLaunch — Landing Page

## Overview
DevLaunch is a fictional learning-platform landing page
created for the Oasis Infobyte SIP Web Development & Designing
Level 1 Landing Page task.

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive media queries

## Features
- Sticky navigation with section links
- Hero section with call-to-action
- Three feature cards
- About section and footer
- Responsive mobile layout

## Project Structure
- index.html — page structure
- style.css — styling and responsive layout
- screenshots/ — project evidence

## How to Run
1. Clone or download this project folder.
2. Open index.html in a modern browser.
3. Resize the browser to test responsive behaviour.

## Screenshots
Add desktop and mobile screenshots from the screenshots folder.

## Learning Outcomes
Practised semantic HTML, CSS layout, typography,
responsive design and browser-based testing.
