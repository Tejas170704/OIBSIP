# DevLaunch — Landing Page

## Project Overview
This project is a responsive landing page developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 1**.

The landing page demonstrates fundamental front-end development skills using HTML5 and CSS3, with a focus on clean design, structured content, and responsive layouts.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Features
- Responsive navigation bar
- Hero section with heading, description, and call-to-action button
- Multiple content sections
- Consistent colors and typography
- Responsive layout for desktop and mobile devices
- Footer section
