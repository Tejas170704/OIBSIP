# Personal Portfolio – Oasis Infobyte Level 1 Task 2

## Project Overview
This project is a personal portfolio website created as part of the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 2**.

The portfolio showcases my technical skills, professional introduction, projects, and contact information through a clean and responsive website.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Flexbox and Media Queries

## Features
- Personal introduction and profile section
- About Me section
- Technical skills showcase
- Project cards with project descriptions
- Contact section
- Interactive navigation
- Smooth scrolling
- Responsive design for different screen sizes

## Projects Showcased
1. **Secure Document Management System** – A document management application built using Spring Boot, MySQL, JWT authentication, AES encryption, and role-based access control.
2. **AI Enterprise Assistant** – An AI-powered enterprise assistant project focused on document processing and retrieval.
