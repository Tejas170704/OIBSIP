
# TempConvert – Temperature Converter

## Overview
A temperature conversion web application that converts values between Celsius, Fahrenheit and Kelvin.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Input validation
- Absolute zero validation
- Responsive interface

## Run
Open index.html in a web browser.
